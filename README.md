Данный репозиторий хранит выполненные практики 1-18.
Для перехода к какой-либо практике следует обратиться к соответствующему коммиту.
Перед использованием установить зависимости с помощью `npm install`.
Для запуска используется `node server.js`.
Фронтенд отображает простую страницу где отображается всё необходимое.
На данный момент проект предаставлят простое pwa приложение с заметками. Есть поддержка заметок с напоминанием, в том числе в уведомлении.
