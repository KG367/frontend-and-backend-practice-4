Данный репозиторий хранит выполненные практики 1-22.
Для перехода к какой-либо практике следует обратиться к соответствующему коммиту.
Перед использованием установить зависимости с помощью `npm install`.
Для запуска используется `node server.js`.
Запуск с указанием порта: `$env:PORT=3001; node server.js`
### nginx
Остановка nginx: nginx -s quit
Аварийная остановка: nginx -s stop
Запуск nginx: start nginx
Nginx конфиг - nginx.conf, разберётесь куда его.
### haproxy
Конфиг - haproxy.cfg.
Запуск: haproxy.exe -f haproxy.cfg.
